Telegram Bot
Kyiv City Assistant

Інтелектуальний асистент для жителів Києва. Моніторинг безпеки, новин, інфраструктури та дозвілля в режимі реального часу.

Команди Відкрити Бота

# МОДУЛІ СИСТЕМИ

News Core

Агрегатор новин з 10 київських Telegram-каналів через Telethon. Фільтрація за ключовими словами, чорний список тем і 3 випадкові свіжі публікації з фото.

Alarm Monitor

Статус повітряної тривоги в Києві через Siren API v3. Відображення типів загроз і посилання на інтерактивну карту.

Energy Monitor

Парсинг офіційного каналу ДТЕК kiev_svet через Telethon. Актуальні фото графіків відключень і очищений текст.

Weather

Поточна погода в Києві через WeatherAPI: температура, вологість, вітер та автоматичний підбір емодзі за умовами.

Air Quality

Індекс якості повітря (AQI) за координатами центру Києва через World Air Quality Index: PM2.5, PM10, NO₂, O₃.

Gastro Guide

Випадковий заклад із локальної бази restaurants_updated.json. Рейтинг, ціни, до 10 фото та геолокація на карті.

Park Finder

Підбір місця для прогулянки з parks.json. Фільтрація за рейтингом, статус відкриття та фото локації.

Metro Router

Прокладання маршруту між станціями київського метро (червона, синя, зелена гілки) з урахуванням пересадок.

Cinema

Розклад сеансів 8 кінотеатрів Multiplex у Києві. Пошук найближчого за геолокацією або ручний вибір, посилання на купівлю квитків.

Theater

Афіша театральних вистав Києва з numotamo.com. Фільтр за 14 жанрами, сортування за датою, посилання на квитки.

Notifications

Персональні налаштування сповіщень про тривогу та графіки відключень. Дані зберігаються в usersinfo.json.

# СПИСОК КОМАНД

/start System
Ініціалізація бота. Реєструє користувача в data/usersinfo.json та відкриває головне меню з кнопками.
📰 Київські новини News
Збір новин про Київ за останні 2 дні:
  1. Підключення до Telegram API через Telethon.
  2. Сканування 10 каналів: @kyivvillage, @K_L_I_V_E, @kyiv_live та інші.
  3. Фільтрація за ключовими словами та чорним списком (тривога, відключення, реклама).
  4. 3 випадкові новини з фото, яких ви ще не бачили.
🚨 Тривога Security
Запит до Siren API v3 для регіону Київ (ID 31):
  • Статус тривоги: спокійно або активна загроза.
  • Типи: повітряна, ракетна, артилерійська, хімічна, радіаційна, вуличні бої.
  • Час останнього оновлення та кнопка «Карта тривог».
☔ Погода в Києві Utility
Запит до WeatherAPI:
  • Температура (фактична та «відчувається як»).
  • Вологість, швидкість вітру, опис умов українською.
  • Емодзі за кодом погоди (сонце, дощ, сніг, хмари).
⚡ Графіки відключень Utility
Моніторинг каналу ДТЕК kiev_svet через Telethon:
  • Пошук останнього повідомлення з фразою «Київ: оновлений графік відключень на сьогодні».
  • Надсилання фото графіка (до 2 зображень) та очищеного тексту.
  • Посилання на перевірку черги за адресою на сайті ДТЕК.
🍽️ Випадковий заклад Leisure
Випадковий ресторан із data/restaurants_updated.json:
  • Картка: назва, адреса, рейтинг, кількість відгуків, ціновий рівень.
  • До 10 локальних фото з папки restaurant_photos.
  • Геолокація закладу на карті Telegram.
🌿 Місце для прогулянки Leisure
Випадковий парк із data/parks.json:
  • Фільтрація закладів без рейтингу, відгуків або фото.
  • Статус відкриття (відчинено / зачинено).
  • Фото місцевості та геолокація.
💨 Якість повітря Utility
Дані з World Air Quality Index для координат Києва:
  • AQI та текстовий статус (від «Добре» до «Небезпечно»).
  • Основний забруднювач і час оновлення.
  • Показники PM2.5, PM10, NO₂, O₃.
🚇 Метро Київ Transport
Побудова маршруту між двома станціями метро:
  • Вибір лінії та станції відправлення (червона, синя, зелена).
  • Вибір лінії та станції призначення.
  • Маршрут BFS-алгоритмом з пересадками (Золоті Ворота ↔ Театральна, Палац спорту ↔ Площа Українських Героїв, Майдан ↔ Хрещатик).
🎬 Кіно сеанси Leisure
Розклад Multiplex у Києві (multiplex.ua):
  • Надіслати геолокацію — бот знайде найближчий з 8 кінотеатрів.
  • Або обрати кінотеатр вручну (Lavina IMAX, Respublika Park, Retroville тощо).
  • Список фільмів на сьогодні → вибір сеансу → посилання на купівлю квитка.
🎭 Театри Leisure
Афіша з numotamo.com:
  • Вибір жанру: драма, комедія, мюзикл, балет, опера, премʼєра та інші (14 категорій).
  • Список найближчих вистав, відсортованих за датою.
  • Деталі вистави: дата, місце, ціна, посилання на квитки.
⚙️ Налаштування System
Персональні сповіщення:
  • 🚨 Сповіщення про тривогу по Києву — увімкнути / вимкнути.
  • ⚡ Сповіщення про графіки відключень — увімкнути / вимкнути.
  • Налаштування зберігаються для кожного користувача окремо.

DATA JSON (users, parks, restaurants)
APIS Siren API, WeatherAPI, WAQI, Multiplex, Numotamo, DTEK (Telegram)

# ЯК КОРИСТУВАТИСЬ

01. Знайдіть бота в Telegram

Відкрийте Telegram і введіть у пошук юзернейм бота або перейдіть за прямим посиланням:

@my_kyiv_bot
Перейти до бота

02. Запустіть бота

Натисніть кнопку START або надішліть /start. Бот відкриє головне меню з 11 функціями.

03. Оберіть потрібну функцію

Використовуйте кнопки меню. Наприклад, натисніть «📰 Київські новини» для дайджесту подій або «⚙️ Налаштування» для сповіщень.

04. Головне меню
